A-Scheme: Homomorphic XOR Emulation

This interactive simulator demonstrates the Base-3 Packing technique used in the A-Scheme to evaluate bitwise XOR operations over additively homomorphic scalar rings without carry-over. This example simulates the processing of a single attribute (an 8-bit byte from the GF(256) field) extracted from the access vectors ri and rj.

Step 1: Byte Deconstruction & Base-3 Packing

We isolate the ℓ-th attribute 𝔯ℓ ∈ GF(256) for both the Sender and Receiver. Their binary representations (x and y ∈ {0, 1}8) are mapped to a scalar value using the superincreasing ternary weight sequence W8 = {1, 3, 9, 27, 81, 243, 729, 2187}.

Step 2: Cryptographic Layer (EC-ElGamal)

The Server evaluates the ciphertext without seeing the plaintext. Let the Receiver's private key be s and public key be Ppub = s · G. The underlying points are masked using random ephemeral scalars (ρ1, ρ2).

1. Sender Encryption (Ciphertext 1):
Maps scalar to point: Pi = 0 · G
C1 = ( R1, M1 ) = ( [ρ1]G, Pi + [ρ1]Ppub )
2. Receiver Encryption (Ciphertext 2):
Maps scalar to point: Pj = 0 · G
C2 = ( R2, M2 ) = ( [ρ2]G, Pj + [ρ2]Ppub )
3. Server-Side Blind Addition:
The server homomorphically adds the ciphertexts point-by-point:
Csum = ( R1+R2, M1+M2 )
Csum = ( [ρ1+ρ2]G, (Pi + Pj) + [ρ1+ρ2]Ppub )
4. Client-Side Decryption & Annihilation:
The Receiver uses their private key s on the first part of the sum to recreate the exact random mask:
Mask = s · (R1+R2) = s · [ρ1+ρ2]G = [ρ1+ρ2]Ppub

Subtracting the Mask from the second part annihilates the randomizers:
M1+M2 - Mask = (Pi + Pj) + [ρ1+ρ2]Ppub - [ρ1+ρ2]Ppub
Payload Point = Pi + Pj = 0 · G

The Receiver runs the Gaudry-Schost algorithm to resolve the ECDLP and extract the pure scalar sum:
Resolved Scalar (Z) = 0

Step 3: Base-3 Extraction & XOR Reconstruction

The Receiver iteratively extracts the ternary coefficients γk from Z and reduces them modulo 2 to recover the exact XORed bits (zk): zk = (⌊Z / 3k⌋ mod 3) mod 2.
